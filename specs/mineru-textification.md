# MinerU 文档文本化

| ID | 行为 |
| --- | --- |
| MINERU-001 | 认证后的 PDF/DOC/DOCX 二进制上传，20 MiB 上限、签名/文档容器检查，独立于 XYZ；共用持久化串行队列、停止、900 秒超时、重启失败语义。 |
| MINERU-002 | 官方 MinerU v4 API：申请上传 URL → 上传 → 轮询 → 下载原始 ZIP；默认 vlm，语言/表格/公式可选；验证成功标志、非空 Markdown 和完整 ZIP。 |
| MINERU-003 | API 凭据和签名 URL 不写入任务/日志；ZIP 解压有路径、符号链接、文件数、总大小限制。 |
| MINERU-004 | 科学应用的「数据挖掘与标注」分类提供文件表单、云端上传说明、参数、日志、停止及下载；Agent em-mineru 与页面使用相同服务。 |

官方 API 当前限制 200 MB/200 页；本演示入口采用更小的 20 MiB 上传限制。
文件页数由上游执行校验；失败保留任务状态与日志，不发布成功结果。
停止不保证上游云任务取消。完整图片/JSON 资产随 results.zip 提供；单独 document.md 为预览副本。
