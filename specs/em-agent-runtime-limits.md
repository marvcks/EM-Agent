# EM-Agent 任务时长与对话附件

| ID | 行为 |
| --- | --- |
| SJT-001 | Agent CLI 对科学任务提交和目录查询发送 X-EM-Agent-Source: agent；JSON 和文档入口保存任务来源。Agent 任务无平台总时长上限，仍支持状态、取消和原有队列/资源/日志/重启规则；手动和无来源的旧任务保留 900 秒超时。来源标记沿用 session key 鉴权，不构成独立权限边界。 |
| ATT-001 | 对话附件单文件最多 50 MiB，一条消息所有附件（含图片）合计最多 100 MiB；等于上限接受，多一个字节拒绝；选择和发送共用校验，并计入已选附件。 |
